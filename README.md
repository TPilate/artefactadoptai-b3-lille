## Organisation du repo
```
README.md               ← tu es ici : échéances, liens, règles
equipe/
  TEMPLATE.md           ← fiche d'auto-évaluation à copier
  prenom-nom.md         ← une fiche par membre
  matrice.md            ← synthèse + rôles attribués
dossier-phase1/
  note-intention.md     ← brouillon de la note (2 pages max)
  presentation-equipe.md← paragraphe "pourquoi nous"
  cv/                   ← un CV PDF par membre
veille/
  sources.md            ← rapports, articles, jeux de données (avec liens)
finale/                 ← code et slides, si on est sélectionnés
decisions.md            ← une ligne par décision prise (date, décision, pourquoi)
```

## Règles d'équipe
- Chacun travaille dans **ses propres fichiers**, donc pas de conflit git pour la phase 1.
- Toute décision d'équipe (défi, piste, rôles) va dans `decisions.md`.
- Les tâches sont des **issues GitHub**, assignées à une personne, avec une date.
- Repo **privé** : il contiendra des CV (données personnelles).
